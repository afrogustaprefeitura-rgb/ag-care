# AG Care — aplicação funcional

Frontend conectado ao Supabase do AG Care.

- Login com Supabase Auth.
- Perfil admin ou cliente via public.perfis_usuario.
- Admin lê empresas e ações reais.
- Cliente lê empresas vinculadas ao próprio usuário e suas ações, respeitando RLS.
- Cliente pode marcar ação como concluída.
- Nenhuma service-role key está no frontend.

## Publicação
Aplicação estática pronta para GitHub Pages.
